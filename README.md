## Introduction

This document is a **course handout** and not a complete course.
Some topics require the guidance of a teacher.

However, students will find a wealth of information here that will, in most cases, enable them to work independently.

---

## Recommended reading

There are some excellent books on Java. These include:

1. **Programming in Java**
   Claude Delannoy – Eyrolles

2. **Java Client-Server**
   Cédric Nicolas, Christophe Avare, Frédéric Najman – Eyrolles

The first book provides an excellent educational introduction to the Java language.
Once you have mastered its content, the second book allows you to tackle more advanced topics:

* Java Beans
* JDBC
* CORBA / RMI

It also offers an industry perspective on Java.

To explore Java in greater depth across various fields, the **"Java Series"** collection from O’Reilly is a useful reference.

For professional use of Java within a J2EE platform:

3. **J2EE Programming**
   Wrox Publishing (distributed by Eyrolles)

## Disclaimer

When this course was first written (1998), the author did not have a perfect grasp of Java coding conventions.

At that time:

* The language was still in its infancy.
* No IDE was used to flag breaches of naming conventions.

Consequently:

* Class and interface names should begin with a capital letter.
* This rule is not consistently followed in the document.

Furthermore, several of the technologies presented are now obsolete:

* RMI
* CORBA
* Swing
* Applets
* The JBuilder IDE

Rather than rewriting this document, a new course was written in 2015:

👉 **Introduction to the Java language and the Spring ecosystem through a case study (2015)**: 
[https://stahe.github.io/en-java-spring-dec-2015/](https://stahe.github.io/en-java-spring-dec-2015/)

This new course is partly based on certain chapters of this document.

It is recommended that you use the 2015 course as your primary resource and consult this document only when it is referenced.
